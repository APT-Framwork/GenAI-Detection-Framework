Model Insights

Understanding the Models
Autoencoder

Compresses event data to detect anomalies by measuring reconstruction error. High error indicates unusual patterns.

  • Input: 313 features
  • Latent: 64 dimensions
  • Purpose: Anomaly detection
VAE

Variational Autoencoder that learns probability distributions to identify malicious events with uncertainty estimates.

  • Input: 191 features
  • Latent: 32 dimensions
  • Purpose: Malicious probability
Transformer

Sequence model that predicts next CKC stage based on event history using attention mechanism.

  • Input: 64-dim sequences
  • Model: 128-dim, 8 heads
  • Purpose: Stage prediction
